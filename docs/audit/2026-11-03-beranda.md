## 1. Analisis Fitur & Menu Beranda Berdasarkan Jenis Pengguna

### A. Pengguna Tamu / Publik (Guest / Belum Masuk)
1. **Top Mini Bar**:
   - Menampilkan identitas Kementerian Perhubungan RI dan BPSDM Perhubungan.
   - Menampilkan informasi kampus dan tagline portal P3M PKTJ dinamis.
   - **Tautan Masuk Tunggal (Discreet Login)**: Sesuai mandat, hanya ada satu tautan masuk sederhana di pojok kanan atas dengan teks minimalis, tanpa tombol masuk mencolok di area navigasi lainnya.
2. **Bilah Navigasi Utama (Desktop ≥ 1024px)**:
   - Logo institusi PKTJ dan judul brand unit P3M.
   - 7 Menu Baku Utama: Beranda, Profil (dropdown 5 sub-menu), Riset (dropdown 3 sub-menu), Pengabdian (dropdown 3 sub-menu), Layanan (dropdown 2 sub-menu), Jurnal (tautan luar terindeks), serta tautan luar kustom CMS.
   - Bebas dari tombol login besar atau bilah duplikasi biru.
3. **Menu Samping Ponsel (Mobile Drawer < 1024px)**:
   - Tombol menu hamburger tunggal berukuran standar ergonomis (48x48px).
   - Seluruh daftar 15+ tautan menu tersusun rapi dengan batas tinggi `max-h-[calc(100dvh-5rem)]` dan `overflow-y-auto`.
   - Area bantalan bawah aman (`pb-28`) memastikan menu paling bawah (SOP, Jurnal) dapat dilihat dan disentuh dengan mudah.
   - Panel autentikasi / tombol masuk disembunyikan untuk tamu.
4. **Bagian Utama Beranda (Hero Section)**:
   - Judul dan teks deskripsi dinamis dari CMS via `Setting`.
   - Penegasan 3 Program Studi PKTJ (D4 RSTJ, D4 TRO, D3 TO).
   - Tombol ajakan bertindak tunggal: "Lihat Berita Terkini" (menggulir halus ke `#berita-terkini`).
   - Penampil Video Profil (rasio 16:9 responsive) dengan tombol buka YouTube dan salin tautan terintegrasi Clipboard API.
5. **Bagian Berita Terkini & Modal Pembaca**:
   - Grid kartu publikasi berita (1 kolom ponsel, 2 kolom tablet, 3 kolom desktop).
   - Jendela baca interaktif (Alpine.js Reader Modal) dengan transisi mulus, tombol tutup [X], klik latar belakang, dan tombol keyboard Escape.
6. **Bilah Kaki (Footer)**:
   - Identitas institusi, alamat kampus, email, dan telepon.
   - Tautan navigasi dan pranala luar nasional. Bebas dari tombol login tamu.

### B. Pengguna Dosen (Terautentikasi / Sudah Masuk)
1. **Top Mini Bar**:
   - Menampilkan salam status masuk: `Masuk: [Nama Dosen] (Dosen) | Dashboard | Keluar`.
   - Tautan `Dashboard` mengarah langsung ke `route('dosen.dashboard')`.
   - Tombol `Keluar` mengirimkan instruksi logout via method POST yang terlindungi token CSRF.
2. **Bilah Navigasi Utama (Desktop)**:
   - Muncul tombol pintasan khusus **Portal Dosen** (`#0B2A59`) di sisi kanan menu utama berdampingan dengan tombol cepat keluar.
3. **Menu Samping Ponsel (Mobile Drawer)**:
   - Menampilkan kartu profil aktif dosen: Nama, keterangan peran "Dosen Peneliti", dan badge status "Aktif".
   - Tombol akses penuh **Buka Portal Dosen**.
   - Tombol keluar sistem dengan gaya warna peringatan lembut (`bg-rose-50`).
4. **Bilah Kaki (Footer)**:
   - Menampilkan tautan khusus berwarna kuning emas: **Buka Portal Dosen SIM**.

### C. Pengguna Reviewer (Terautentikasi / Sudah Masuk)
1. **Top Mini Bar**:
   - Menampilkan salam status masuk: `Masuk: [Nama Reviewer] (Reviewer) | Dashboard | Keluar`.
   - Tautan `Dashboard` mengarah langsung ke `route('reviewer.dashboard')`.
   - Tombol `Keluar` siap digunakan.
2. **Bilah Navigasi Utama (Desktop)**:
   - Muncul tombol pintasan khusus **Portal Reviewer** di sisi kanan menu utama.
3. **Menu Samping Ponsel (Mobile Drawer)**:
   - Kartu profil aktif reviewer: Nama, peran "Reviewer Proposal", dan badge status "Aktif".
   - Tombol penuh **Buka Portal Reviewer**.
   - Tombol keluar sistem.
4. **Bilah Kaki (Footer)**:
   - Menampilkan tautan khusus: **Buka Portal Reviewer SIM**.

### D. Pengguna Administrator P3M (Admin)
1. **Top Mini Bar**:
   - Menampilkan salam status masuk: `Masuk: [Nama Admin] (Admin) | Dashboard | Keluar`.
   - Tautan `Dashboard` mengarah langsung ke `route('admin.dashboard')`.
2. **Bilah Navigasi Utama (Desktop)**:
   - Muncul tombol pintasan khusus **Panel Admin** di sisi kanan menu utama.
3. **Menu Samping Ponsel (Mobile Drawer)**:
   - Kartu profil aktif administrator: Nama, peran "Administrator P3M", dan badge status "Aktif".
   - Tombol penuh **Buka Panel Admin**.
   - Tombol keluar sistem.
4. **Bilah Kaki (Footer)**:
